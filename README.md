# News Parser & Monitoring Service

Сервис для автоматического сбора новостей вузов (НИЯУ МИФИ, РТУ МИРЭА, КФУ) и формирования персональной рассылки на основе интересов пользователей.

## Структура проекта

- `main.py` — центральный координатор-планировщик и формирование рассылки
- `seed_users.py` — первичное наполнение базы тестовыми пользователями и их категориями
- `db_functions.py` — модуль DDL и операций с базой данных SQLite
- `config.json` — конфигурационный файл запуска сервиса
- `parsers/` — модули парсинга новостей вузов:
  - `parser_mephi.py` (НИЯУ МИФИ)
  - `parser_mirea.py` (РТУ МИРЭА)
  - `parser_kfu.py` (КФУ)
- `newsletter.txt` — результирующий файл сформированной рассылки
